# 变更记录

## 1.4.0 — 2026-10-26

- 恢复一次性原型禁止用于生产、原型代码不得直接演变为生产代码的限制，以及静态 HTML/Figma 原型约定
- 恢复不确定的能力承诺仅作内部工程目标、不进入验收承诺或 UI 文案的边界
- 恢复 1.3.0 删去的 Amazon 方法论章节与案例，明确其参考定位
- 移除 Agent Harness、LLM Judge 等领域专项规定，测试方法由项目自身需求与验收标准决定
- 保留已确认的需求规格、系统功能清单、联合规划、分层写作及交叉检查要求

## 1.3.0 — 2026-10-26

> 以下为历史变更记录；其中原型复用边界、领域专项规定及参考资料删减已由 1.4.0 修正。

- 全面核对入口、流程参考与全部模板，统一各成果的用途、主记录、状态和衔接关系
- 重组模板为概述、分类细节、证据和行动，新增成果质量参考及相互关联的写作示例
- 修正原型提前要求完整实测、目标与结果混淆、任务与测试循环依赖、关键指标失败放行等冲突
- 区分文档版本与产物版本、发布计划与实际结果、发布成功与交付验收
- AI/Agent 保留主观质量的 LLM Judge 与专家复核，客观指标采用实际测量与断言
- 澄清硬件阶段循环、已有确认复用和外部操作授权，精简重复检查与事实性旁支
- 文件名使用 PRFAQ，修正文档版本及更新授权的歧义
